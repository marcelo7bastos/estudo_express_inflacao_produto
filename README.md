# Estudos expressos de inflação por produto

Relatórios técnicos curtos sobre a evolução do preço de alimentos no Brasil e as perspectivas para os anos seguintes, com dados oficiais (IBGE, Conab, NOAA, Banco Mundial, FAO) e código aberto.

**Site:** https://marcelo7bastos.github.io/estudo_express_inflacao_produto/

**Autor:** Marcelo Cabreira Bastos
